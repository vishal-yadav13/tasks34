# Simple Web Server with Node.js

## About the Project

This project is a simple web server created using Node.js.
It uses the built-in HTTP module to handle different routes
and serve HTML pages.

## Technologies Used

- Node.js
- HTML
- CSS

## Routes

- `/home` - Home page
- `/about` - About page
- `/contact` - Contact page

## Port

The server runs on port 3000.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

   node server.js

4. Open the browser and visit:

   http://localhost:3000/home

## 404 Error Handling

If an invalid route is requested, the server displays a
404 Page Not Found message.
